# design_principles.md

## Anti-AI-slop checklist (hackathon judges explicitly penalize this)
- UI must fit the viewport on first load — no scrolling required to understand what the app is.
- Every screen needs a distinct visual identity (custom palette + type choices), not default
  component-library look.
- Copy (prompts, confessions, this-or-that questions) must sound like a real Redditor wrote it —
  specific, slightly unhinged, culturally current — never generic ("How are you feeling today?").
  Draft with AI, then hand-edit every line before shipping.
- Micro-interactions (button press states, reveal animations for aggregates) should feel snappy,
  not default browser behavior.

## Tone for daily content
- Confessions/questions should be specific and a little chaotic, not sanitized corporate copy.
- Prefer concrete scenarios over abstract feelings ("Muted my best friend two years ago" not
  "I feel disconnected from friends").
- Always safe-for-Reddit: no content that trivializes self-harm, illegal acts, or targets
  identifiable individuals. When in doubt, cut it — a human reviews every batch before it ships.

## Visual identity direction
- Lean into a "diary/arcade" hybrid aesthetic: warm, slightly retro accents (like a polaroid or
  arcade ticket) combined with clean modern typography — avoid looking like a corporate survey
  tool or a generic quiz app template.
